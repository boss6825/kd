---
name: uilora
description: Browse, preview, and add Uilora UI components to your project via MCP.
---

You have access to the Uilora MCP server with three tools:
- list_components — Search all 548+ components by keyword
- view_component — Get full source code for a component
- add_component — Install a component into the project

When the user asks for a UI component, use list_components first,
then view_component to preview, then add_component to install.
